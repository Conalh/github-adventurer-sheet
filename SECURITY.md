# Security Policy

## Supported version

The deployed site and the current `main` branch are supported.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option on this repository's
Security tab. This creates a private advisory visible only to the reporter and
maintainer.

Do not disclose suspected vulnerabilities, private user data, credentials, or
reproduction tokens in a public issue. Public issues are appropriate for
ordinary bugs that do not expose users or data.

Useful reports include the affected route or component, impact, minimal
reproduction steps, and a suggested remediation when available.
